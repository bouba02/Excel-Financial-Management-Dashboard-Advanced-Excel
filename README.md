## 📁 Structure du Système (6 Onglets)

```
Excel-Dashboard-Pilotage-Financier/
├── 📋 ONGLET 1 : PARAMETRES
│   ├── Configuration catégories dépenses
│   ├── Règles comptables
│   ├── Périodes de reporting (mois/trimestre/année)
│   └── Contrôles de validation
│
├── 💰 ONGLET 2 : VENTES_REVENUS
│   ├── Saisie revenus structurée
│   ├── Colonnes : Date | Client | Montant | Catégorie | Statut
│   ├── Détection doublons automatique
│   └── Pivot clients principaux
│
├── 💸 ONGLET 3 : DEPENSES
│   ├── Enregistrement par catégorie
│   ├── Colonnes : Date | Fournisseur | Montant | Catégorie | Description
│   ├── Validation montants positifs
│   └── Alertes dépenses anormales (>seuil)
│
├── 📊 ONGLET 4 : TABLEAU_DE_BORD ⭐ (CŒUR DU SYSTÈME)
│   ├── Zone 1 : KPIs Essentiels (CA, Dépenses, Résultat, Marge)
│   ├── Zone 2 : Graphiques Visuels (CA N vs N-1, CA vs Dépenses)
│   ├── Zone 3 : Analyses Comparées (Trimestriel, Répartition)
│   └── Zone 4 : Détails Opérationnels (Top Clients, Détails mensuels)
│
├── 📤 ONGLET 5 : EXPORT_COMPTABLE
│   └── Format standard pour expert-comptable
│
└── 📖 ONGLET 6 : GUIDE_UTILISATION
    ├── Mode d'emploi étape par étape
    ├── FAQ cas courants
    └── Dépannage
```

## ⚙️ Fonctionnalités Avancées

### **🔒 Sécurité & Contrôles**

- ✅ **Listes déroulantes** : Évite saisies anarchiques
- ✅ **Validation données** : Montants positifs, formats cohérents
- ✅ **Verrous formules** : Protection contre suppressions accidentelles
- ✅ **Historique modifications** : Changelog automatique intégré
- ✅ **Détection doublons** : Alertes sur transactions en double

### **🚨 Alertes Automatiques**

```
🔴 ALERTE CRITIQUE (>10% écart budget)
🟠 ATTENTION (dépense anormale détectée)
🟢 OK (tout sous contrôle)
```

- Signalement écarts budgétaires >10% (surlignage auto)
- Détection dépenses anormales vs historique
- Alertes clients en retard d'encaissement

### **📈 Analyses Temps Réel**

- **Comparaisons N vs N-1** : Année/mois précédent
- **Moyennes mobiles** : Détection tendances
- **Projections simples** : Si tendance continue
- **Ratios automatiques** : Marge %, taux croissance

### **💾 Exports Automatisés**

- Export comptable **1 clic** (format standard)
- Export client/fournisseur
- Export TVA si applicable
- Format prêt pour expert-comptable
